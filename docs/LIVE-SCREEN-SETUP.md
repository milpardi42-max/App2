# راه‌اندازی نمایش زنده گوشی دوم

این قابلیت برای استفاده رضایتی روی دستگاه شخصی طراحی شده است. شروع هر نوبت اشتراک به تأیید پنجره سیستمی Android MediaProjection نیاز دارد و هنگام اشتراک، اعلان دائمی اندروید نمایش داده می‌شود.

## ۱. پایگاه داده

فایل `supabase/SETUP-ALL-IN-ONE.sql` را در SQL Editor پروژه Supabase اجرا کنید. بخش پایانی فایل جدول کوتاه‌عمر `screen_share_sessions` را ایجاد می‌کند.

## ۲. متغیرهای ساخت APK

این مقادیر را به GitHub Actions Secrets پروژه اضافه کنید:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_ANON_KEY`
- `EXPO_PUBLIC_TURN_URL` (برای اینترنت عمومی توصیه می‌شود)
- `EXPO_PUBLIC_TURN_USERNAME`
- `EXPO_PUBLIC_TURN_CREDENTIAL`

بدون TURN، WebRTC معمولاً روی یک Wi-Fi یا شبکه‌هایی با NAT ساده کار می‌کند؛ اما اتصال بین اینترنت سیم‌کارت و شبکه خانگی تضمین‌شده نیست. برای استفاده دائمی، اعتبارنامه کوتاه‌عمر TURN امن‌تر از قرار دادن رمز ثابت داخل APK است.

## ۳. روش استفاده

1. دو گوشی را با کد شش‌رقمی جفت کنید.
2. روی گوشی دوم وارد صفحه وضعیت شوید و «شروع اشتراک صفحه» را بزنید.
3. پنجره رسمی اندروید را تأیید کنید.
4. در گوشی اول، «کنترل از راه دور» و سپس «نمایش زنده گوشی دوم» را باز کنید.
5. برای پایان، در هرکدام از گوشی‌ها دکمه توقف/بستن را بزنید یا اشتراک را از اعلان اندروید متوقف کنید.

## محدودیت اندروید

صفحات محافظت‌شده با `FLAG_SECURE`، از جمله بعضی برنامه‌های بانکی و مدیریت رمز، ممکن است سیاه دیده شوند. این محدودیت سیستم‌عامل است. نسخه فعلی انتقال تصویر زنده را پیاده‌سازی می‌کند؛ کنترل لمس از راه دور نیازمند سرویس Accessibility جداگانه و فعال‌سازی دستی آن در تنظیمات گوشی دوم است.
